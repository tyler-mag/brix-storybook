## When to use

Use one primary button per decision point. A modal footer, form section, or toolbar can each be a decision point when the user encounters it independently. Use Secondary for an adjacent supporting action and Danger only for a destructive commitment.

Use a short, specific verb that describes the result. Use a link when the action only navigates, and do not use a second primary button to represent a supporting or dismissive action.

## AI decision contract

```yaml
component: Button
intent: Trigger an immediate product action at the correct level of hierarchy.
use_when:
  - The user can act now and the result is clear from a verb-led label.
  - The action submits, confirms, starts, supports, or destructively commits a task.
avoid_when:
  - The destination is another page; use a link.
required_context:
  - surrounding_control_density
  - current_decision_point
  - action_consequence
default_configuration:
  variant: primary
  size: default
variant_rules:
  primary: Use for the one action that advances the current decision point.
  secondary: Use for a supporting, deferring, or alternative action beside Primary.
  danger: Use for the final destructive or difficult-to-reverse commitment.
size_rules:
  default: Use in standard product workflows; height is exactly 36px.
  small: Use in dense cards, ribbons, rows, or embedded controls; height is exactly 28px.
accessibility_invariants:
  - Render a native button and retain its visible text label.
  - Preserve the Fizz focus ring for keyboard and programmatic focus.
  - Expose disabled state with the native disabled attribute.
ambiguity_resolution: If two actions appear equally important, clarify the decision hierarchy instead of rendering two Primary buttons.
```

## Content

- Lead with a specific verb when the product action is known.
- Describe the result, not the UI mechanics.
- Keep the label short enough to scan without wrapping.

## Accessibility

- The component renders a native `button` and defaults to `type="button"`.
- Enter and Space retain native activation behavior.
- Disabled state prevents activation and is exposed to assistive technology.
- The artifact-authored focus ring remains visible without the global Storybook outline changing its appearance.
