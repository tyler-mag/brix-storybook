# Audio transcript player

<span className="brix-doc-status">Artifact parity</span>

Use the audio transcript player to review a recorded call and jump to time-coded events without leaving playback.

## When to use

Use this component for a completed recording with reliable event start and end times. Use the Live call card while a call is active. Do not fabricate event timing or replace ranges with point markers.

## Interaction

- The one-second preview timer advances while playing.
- Clicking the track or an event range seeks and starts playback.
- Releasing the draggable handle seeks and starts playback, even if playback was previously paused.
- Event ranges become 80% opaque on hover and show one-line dark tooltips eight pixels above the track.
- The handle changes from grab to grabbing and darkens while dragged.

Invisible semantics add labels and keyboard seeking without changing the artifact canvas.
