# Live call card

<span className="brix-doc-status">Artifact parity</span>

Use the live call card to monitor one active outbound call and expose takeover, mute, transcript, and tool activity in one compact surface.

## Default usage

## When to use

Use this composition while a call is active. For a completed recording, use the Audio transcript player instead. Do not place unrelated metrics or historical context inside the card; the fixed composition is reserved for the current call.

## Context variants

Show the agent name when calls are grouped by agent. Omit the repeated name in a mixed feed where surrounding context identifies the agent.

## Anatomy

1. Tool failure badge and optional underlined agent name
2. Take over conversation and mute controls
3. Direction, phone number, and elapsed time
4. Scrollable agent/customer transcript
5. Performing tool disclosure with parameters and progress

## Interaction

- Hovering the card changes only its two-pixel border to Sprig 800.
- Mute toggles the visible volume icon and pressed state.
- Expanding “Performing tool • 00:10” reveals the exact parameter and progress copy, then smooth-scrolls the disclosure into view after 100ms.
- The tool spinner rotates continuously while the operation is in progress.

The source artifact’s exact error badge and Agent transcript label colors measure below 4.5:1 at 12px. Parity stories retain those colors and document the limitation instead of silently redesigning them.
