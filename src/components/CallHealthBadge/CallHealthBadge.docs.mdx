# Call center badge

<span className="brix-doc-status">Artifact parity</span>

Use these compact badges to surface a detected call condition or live-call status inside a constrained card.

## Default usage

<Canvas of={Stories.DefaultUsage} />

<Controls of={Stories.DefaultUsage} />

## When to use

Use one badge for each supported condition that is currently true. Keep the detector's exact label. Do not use a badge as a substitute for explanatory content when the user needs evidence, history, or a recommended response.

## Accessibility

The indicator is decorative; the visible text carries the meaning. Reduced-motion preferences stop the pulse without removing the label or color.

The source artifact’s exact error and warning color pairs measure below 4.5:1 at 12px. The parity stories document that known limitation and exempt only the automated color-contrast rule; no colors were silently changed.
